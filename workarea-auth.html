Sobre eXeLearning

eXeLearning v0.0.0-alpha

¡Esta es una versión para pruebas! Este software se proporciona para pruebas y no debe ser distribuido. Está en desarrollo y sujeto a cambios sustanciales. Considera la información incluida como incompleta y úsala con precaución.

eXeLearning es una herramienta de software libre bajo licencia GNU Affero GPL que se puede utilizar para crear contenidos web educativos interactivos. eXeLearning puede generar contenidos en diferentes formatos y te permite crear páginas web fácilmente navegables. Todos los materiales educativos generados con eXeLearning se pueden exportar en diferentes formatos digitales para ser utilizados de forma independiente o para integrarlos en un LMS (Learning Management System) como Moodle.
