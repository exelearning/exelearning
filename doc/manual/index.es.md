# Manual de eXeLearning

El manual de uso explica qué es eXeLearning, cómo se instala, el entorno de trabajo, cada iDevice
con su ejemplo y la descarga y publicación de los recursos. Está escrito con el propio eXeLearning y
se publica de nuevo con **cada versión**, de modo que cada versión de eXeLearning tiene su manual.

Este es el manual de la aplicación. La guía para usar eXeLearning dentro de Moodle, WordPress y
otras plataformas es un documento distinto: consulta [Plugins](../plugins/index.es.md).

## Descargar una versión concreta

Cada [versión de eXeLearning](https://github.com/exelearning/exelearning/releases) incluye dos
archivos del manual con la versión en el nombre:

- `exelearning-manual-es-<versión>.elpx`: el proyecto, para abrirlo y adaptarlo en eXeLearning.
- `exelearning-manual-es-<versión>-html.zip`: el sitio web completo; descomprímelo y abre
  `index.html`, sin conexión.

Por ejemplo, `exelearning-manual-es-v4.0.6.elpx` es el manual de eXeLearning 4.0.6. Si el manual se
corrige después de publicar la versión, la corrección se añade junto a los archivos originales con
un número (`exelearning-manual-es-v4.0.6-1.elpx`); los archivos ya publicados no se sustituyen.
