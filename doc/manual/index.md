# eXeLearning user manual

The user manual explains what eXeLearning is, how to install it, the working environment, every
iDevice with a working example, and how to download and publish your resources. It is written with
eXeLearning itself and published again with **every release**, so each version of eXeLearning has
its matching manual.

This is the manual of the application. The guide to using eXeLearning inside Moodle, WordPress and
other platforms is a separate document: see [Plugins](../plugins/index.md).

## Download a specific version

Every [eXeLearning release](https://github.com/exelearning/exelearning/releases) includes, for each
language, two files named after the release:

- `exelearning-manual-<language>-<version>.elpx`: the project, to open and adapt in eXeLearning.
- `exelearning-manual-<language>-<version>-html.zip`: the complete website; unzip it and open
  `index.html`, no connection needed.

For example, `exelearning-manual-en-v4.0.6.elpx` is the English manual of eXeLearning 4.0.6. A
manual corrected after its release is added next to the original files with a correction number
(`exelearning-manual-en-v4.0.6-1.elpx`); published files are never replaced.

## Improve the manual

Found a typo, an outdated screenshot or a broken link? Open an
[issue](https://github.com/exelearning/exelearning/issues) with the page it affects. To change the
manual yourself, or to start the manual in another language, follow
[Edit, build and release the manual](../development/user-manual.md).
