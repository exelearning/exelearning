# Plugins de integración de eXeLearning

Este manual para **eXeLearning 4.0.6** reúne las instrucciones de **instalación y configuración para la
administración** y las indicaciones de **uso para el profesorado**. Incluye Moodle, Nextcloud,
WordPress, Omeka S, Google Drive y OneDrive, con los textos, imágenes y diseño revisados.

<a class="md-button md-button--primary" href="../manual-es/index.html">Abrir el manual completo</a>

[Descargar el proyecto de eXeLearning (.elpx)](manual.es.elpx){ .md-button download }

El manual conserva su propio menú, buscador y diseño. Elige tu plataforma para consultar sus
instrucciones. Abre el archivo `.elpx` en eXeLearning para adaptar el contenido y publicarlo como
sitio web, paquete SCORM o ePub.
